# Java Practices

A small repository for practicing Java fundamentals, object-oriented programming, and coding exercises.

## Repository Structure

- `Basics/`
  - Java syntax and foundational examples.
  - Includes simple programs for learning variables, loops, and core language constructs.

- `Opps/`
  - Object-oriented programming examples.
  - Contains classes and examples that demonstrate encapsulation, inheritance, and class design.

- `Practices/`
  - Practice problems and sample programs.
  - Includes example files such as `Main.java` and `increment.java`.

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed.
- A terminal or command prompt.

### Compile and Run

1. Open a terminal in the repository root.
2. Compile a Java file:
   ```powershell
   javac Practices\Main.java
   javac Practices\increment.java
   ```
3. Run the compiled class:
   ```powershell
   java Practices.Main
   ```

> If your files are in other folders, adjust the path accordingly.

## Notes

- Remove generated `.class` files before committing if they should not be tracked.
- Use the `Basics` and `Opps` folders to review syntax and design patterns before solving practice problems.

## Recommended Workflow

1. Study examples in `Basics/`.
2. Explore object-oriented examples in `Opps/`.
3. Solve practice problems in `Practices/`.
4. Compile and run code frequently to verify behavior.
